Spot the Difference is a complete, original spot-the-difference game that runs offline in a desktop browser. Six hand-drawn vector scenes (Morning Market, Harbour at Dusk, City Park, Old Train Station, Beach Day, Night Library) are each shown twice side by side, with 8 to 10 differences hidden in the busy detail. Click a difference on either picture to circle it on both, build a streak multiplier, spend hints, and beat the clock. Three difficulty tiers (Easy 7 differences in 3:00, Medium 9 in 2:30, Hard 10 in 2:00), 1-3 star level results, a best score saved in localStorage, and WebAudio synth sounds throughout. All art is drawn procedurally on canvas, no image or sound files, no network requests.

## Run it

```sh
cd game
python3 -m http.server 8080
```

Then open http://localhost:8080 in a desktop browser and click a scene to play. Keys: 1-6 select a scene, H hint, N next level, R restart, M mute, Esc menu.
